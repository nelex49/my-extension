# Demo and Design Files

This directory contains demo and design exploration files that were used during development but are not part of the production extension.

## Files

### `design3-demo.html`

- **Purpose**: Standalone demo of the SubfolderView component
- **Status**: Development artifact - functionality fully integrated into extension
- **Usage**: Can be opened in a browser to preview the SubfolderView UI
- **Note**: Uses `src/styles/subfolder-view.css` for styling

### `organize-subs-designs.html`

- **Purpose**: Design exploration file with multiple UI layout variations
- **Status**: Historical design iterations - final design implemented in extension
- **Usage**: Reference for design evolution
- **Note**: Contains inline styles and multiple design concepts

## Recommendation

These files can be:

- **Kept** for reference/documentation purposes
- **Moved** to a `demos/` or `archive/` folder
- **Removed** if no longer needed

They are not included in the extension build and do not affect functionality.
