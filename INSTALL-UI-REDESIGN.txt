YouTube Subscription Manager - compact folder forms

INSTALL / TEST IN CHROME
1. Keep your repository on the ui-redesign branch. Do not merge this work to main yet.
2. Replace your working tree with the files in this package (or copy only the changed files listed below).
3. Open chrome://extensions.
4. Turn on Developer mode.
5. If the extension is already loaded, click Reload on its card. Otherwise choose Load unpacked and select this extension folder.
6. Open or refresh a YouTube tab. A full page refresh is important after reloading a content-script extension.
7. Sign in through the extension if required, then open YouTube > Manage Subscriptions.

AUTOMATED REGRESSION CHECKS
From the extension root, with Node.js installed:
  node tests/retrieval.cjs
  node tests/startup.cjs
  node tests/dialogs.cjs
  node tests/manage.cjs

All four pass in the supplied package.

LIVE CHROME CHECKS STILL REQUIRED
- Create a parent and a subfolder and confirm the compact dark form, muted defaults and 20-character limit.
- Use Custom colour and confirm Chrome's native colour picker opens and the exact chosen colour appears in Manage and the browsing sidebar.
- Try very light and very dark custom colours and confirm text remains readable.
- Open parent editors from a visible parent tab and from All Folders. Confirm the editor anchors beside the three-dot button and the folder is not selected merely by clicking the dots.
- Open a subfolder editor from its Manage row and confirm the parent name is shown.
- Rename/recolour parent and subfolder records containing channels. Confirm assignments and subfolders are preserved.
- Confirm duplicate parent names are rejected; duplicate subfolder names are rejected only within the same parent.
- Press Escape and click outside an editor. Confirm unsaved changes are discarded.
- Delete a subfolder and then a parent. Confirm the small in-form confirmation appears, counts/navigation update, and no YouTube subscription is removed. Deleted-folder channels should appear as Uncategorised when they have no other assignment.
- Force/reproduce a storage failure if practical and confirm the editor stays open with an error and existing data remains intact.
- Recheck login/logout, subscription retrieval, counts, navigation, Move and Remove.
