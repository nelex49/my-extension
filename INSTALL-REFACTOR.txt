FOLDER CODE REFACTOR

BASELINE
This package is based on the cumulative patches you confirmed working and pushed on 13 October, including Move search and All Folders scroll memory. The repeatedly attached source ZIP was the older 12 October snapshot and has not been used to overwrite those changes.

1. CHECK YOUR WORKING COPY
In your existing project terminal:

git status

If there are uncommitted changes, save and commit the intended work first. Do not discard it. If you made additional code changes since the last tested patch, compare them before replacing files.

Optional separate branch for this pass, starting on ui-redesign with a clean working tree:

git switch ui-redesign
git switch -c folder-refactor

2. INSTALL
This package contains the COMPLETE src folder, not a partial patch.
Delete the existing project src folder, then copy this package's src folder into the project root. This removes the retired files. Your previous source is retained in your existing Git commit.
Replace manifest.json and README.md with the supplied versions.
Copy the tests folder into the project root. If you already have a tests folder, merge it and replace only matching files.
Do not copy INSTALL-REFACTOR.txt or REFACTOR-NOTES.md unless you want them in the repository.
Leave background.js, popup.html and popup.js in place. They are unchanged and are not included in this update package.
Do not delete the project folder or its Git repository.

3. RELOAD AND TEST
Reload the extension at chrome://extensions, then refresh YouTube.
Confirm login/logout, sidebar expansion, channel links, scrolling, counts, stable parent tabs and All Folders scroll memory.
Create a parent: it should become active in Manage. Create at least three subfolders inside it: the old limit is disabled. Test Cancel, close, outside click, Escape, colour preview and dragging.
Test Move through both steps, optional search, Back, description, Remove and unchanged account total.
The dialogs keep the existing light appearance; the dark redesign and deletion controls are a later pass.

Optional automated checks if Node.js is installed:
node tests/startup.cjs
node tests/dialogs.cjs
node tests/manage.cjs
node tests/retrieval.cjs

4. COMMIT AFTER LIVE TESTING

git status
git add -A
git diff --cached --stat

Review the staged files and deletions. git add -A includes all current changes, so remove unrelated items from staging if necessary.

git commit -m "Refactor folder dialogs and shared sidebar helpers"
git push -u origin folder-refactor

Those push commands assume you created folder-refactor above. If you stayed on ui-redesign, use git push origin ui-redesign instead. Do not merge to main yet.
